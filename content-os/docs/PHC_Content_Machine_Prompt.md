### FORMAT 7: VIDEO SCRIPT — PROPERTY / SHOWROOM TOUR (JP + EN paired)

This is the format for short-form social video scripts (TikTok/Reels/YouTube Shorts). Always produce Japanese and English versions together. Based on PHC's actual production style.

**Length:** 30–45 seconds spoken per version (approx 80–120 words per script)
**Always include estimated runtime at the top of the output.**

**Content formula (follow this order every time):**

2. Show what is new or important
3. Explain why viewers should care
4. Add one useful investor or buyer insight

6. End with the full standard CTA

---

**HOOK RULES (critical):**

Always produce **3 hook options** — let the user pick. Hooks must be strong, not generic.

❌ NEVER start with: "今日はショールームに来ています" / "Today I visited the showroom"
✅ STRONG showroom hooks:
- "ガトータワーの1ベッドルーム、実際に見られるようになりました。"
- "写真だけでは分からない部分を、今日はショールームで確認してきました。"
- "この間取りを見るとき、広さだけで判断しないことが大切です。"

The hook should establish what is new or surprising — not just where you are.

**Each version contains 3 parts:**

**Part A — 3 Hook Options**
Three strong opening lines to choose from. Written in the same broken-line script style.

**Part B — Spoken Script** (the narration, broken into short lines for video pacing):
- Open with hook option 1 (or whichever is strongest for this content)
- Body: 3–4 short sections describing what viewers can see/learn. Break every 1–2 clauses onto a new line — this is for subtitle readability during video playback
- Value insight for showroom videos: "ショールームで見るべきポイントは、広さだけではありません。家具を置いたときのスペースの使い方、生活動線、そして日々の暮らしのイメージ。写真だけでは分かりにくい部分が、実際に来ると確認しやすくなります。"
- End with full standard CTA block (never shorten)

**Part C — On-Screen Text Flow** (numbered list, 8–12 items):
- Very short phrases, 2–5 words maximum each
- These appear as text overlays during video editing
- Last 2 items should always be the comment CTA + brand line
- JP example: "広さだけではない", "コメントで「GATO」", "買う前に、正しく比較"
- EN example: "Not Only About Size", "Furniture Layout", "Comment GATO"

**Part D — Caption** (for the social media post beneath the video):
- 3 short paragraphs
- Para 1: What you visited / context (brief, factual)
- Para 2: What viewers will learn or why it's worth seeing in person (showroom insight)
- Para 3: Full standard CTA (never shorten — always include "価格、支払い条件、空きユニット、そして物件比較まで分かりやすくご案内します。買う前に、正しく比較しましょう。")

**Japanese tone rules:**
- Register: 丁寧語 (polite), natural spoken — not stiff business Japanese
- Line breaks: every 1–2 short clauses, never long sentences
- Discovery tone for body: "今日はショールームで、〜を見せていただきました" — use in the body, not as the hook
- Avoid: hard-sell, urgency, superlatives
- Never use: 絶対おすすめです / 今すぐ買うべきです / 必ず値上がりします / 最高の物件です
- Use instead: このプロジェクトは、こういう考え方の方に合うかもしれません / 条件はユニットによって異なるため、事前確認が必要です

**English tone rules:**
- Mirror the Japanese structure exactly
- Short, clear sentences. Break them across lines for pacing
- Tone: calm advisory — not salesy, not luxury advertisement
- CTA: always "please comment [KEYWORD]" — do not shorten
