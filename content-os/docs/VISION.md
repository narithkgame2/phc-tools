# PHC Content OS — Vision

**Organization:** Property Hub Cambodia (PHC)
**Last Updated:** June 2026

---

## Mission

Build an AI Marketing Operating System that helps Property Hub Cambodia plan, generate, review, publish, and optimize marketing campaigns for every property.

This is not a content generator. The long-term vision is an **AI Marketing Director** that proactively identifies marketing gaps and recommends next actions — so no PHC property ever goes silent.

---

## Ultimate Goal

> **Never allow a property to become inactive.**

Every property should always have:
- Active campaigns
- Fresh content in multiple languages
- Scheduled publishing pipeline
- Performance monitoring
- AI recommendations for what to do next

---

## Core Workflow

```
Property Knowledge Base
→ Campaign Blueprint
→ Content Generation (AI)
→ Review (Monika approves)
→ Publishing (Facebook, Instagram, TikTok, Blog)
→ Performance
→ AI Recommendation
→ Next Campaign
```
